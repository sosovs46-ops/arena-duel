# arena-duel

Простой браузерный проект с викториной и поддержкой Firebase для будущего Telegram Mini App.

Что уже есть:
- публичная стартовая страница
- режимы: ученик / учитель / бот / 2 игрока
- базовый журнал результатов
- локальное сохранение данных через localStorage
- готовый Firebase слой для включения в продакшн

Как открыть публично:
1. Загрузите репозиторий на GitHub.
2. Включите GitHub Pages.
3. Укажите Source: main / root.
4. После публикации страница будет доступна по ссылке вида:
   https://<username>.github.io/arena-duel/

Что нужно сделать для Firebase:
1. Создайте проект в Firebase Console.
2. Добавьте веб-приложение.
3. Откройте файл firebase-config.js.
4. Замените значения на реальные из Firebase.
5. Включите Firestore по умолчанию.
6. Обновите правила Firestore, если нужно хранить записи.

Важно:
- Для Telegram Mini App нужна HTTPS-ссылка, а не открытие файла локально.
- Для реального продакшна лучше не хранить PIN-коды в открытом клиентском коде.
